# AG-1 Functional Demonstration Results

Run 2026-11-07 23:00 UTC against tenuo 0.3.5 on Python 3.12.15, using Forgejo 16.0.6+gitea-1.22.0 with a separate test service and staging sink. 10 of 10 steps met their expected outcome.

Harness commit: `4702b6c20664fb55e244f58af291e2c8d20ea261`. [Workflow run](https://github.com/tenuo-ai/nccoe-ag1-harness/actions/runs/42423105182).

The result describes the implementation integrated with the AG-1 reference enforcement point. The responsibility table below identifies which component supplies each control.
