# AG-1 Functional Demonstration Results

Run 2026-11-07 00:54 UTC against tenuo 0.3.5 on Python 3.12.15, with Forgejo 16.0.6+gitea-1.22.0 with a separate test service and staging sink as the SCM service. 10 of 10 steps met their expected outcome.

The result describes the implementation integrated with the AG-1 reference enforcement point. The responsibility table below identifies which component supplies each control.
